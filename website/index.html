02 / FIND YOUR SOUND

Your brief.
Your workflow.

A short prompt, a file full of lyrics, or a command inside an agent loop. Same simple interface.

Style, tempo, vocals, and duration belong in your prompt. The default model is lyria-3.5.

A soundtrack for a slower evening.

lyria-cli generate \
  --prompt 'Mellow bossa nova, nylon guitar,
    soft percussion, instrumental only' \
  --output ./evening.mp3

Put your musical directions and lyrics in song.txt.

lyria-cli generate \
  --prompt-file ./song.txt \
  --output ./song.mp3

Use section tags such as [Verse] and [Chorus] in your prompt file.

Give your agent a result it can work with.

lyria-cli generate \
  --prompt 'Gentle ambient synth, no vocals' \
  --output ./ambient.mp3 \
  --json

A FEW DETAILS

Before you press enter.

Which models can I use?

The default is lyria-3.5. You can select lyria-3-clip-preview with --model for a fixed 30-second clip. Your Gemini API key needs access to the selected model.

Can I generate songs with lyrics?

Yes. Put your musical directions, language, vocal style, and lyrics in the prompt or a UTF-8 prompt file. For instrumental music, explicitly ask for no vocals. See the Lyria prompt guide.

What does generation cost?

You bring your own Gemini API key, and usage is billed by your API provider. Check Google's current pricing. The CLI does not automatically retry a generation request.

Can I stream music or export WAV?

This version generates one complete MP3 per request. It supports text prompts, including lyrics. Real-time streaming, image input, WAV output, and audio editing are outside the current CLI.

Where can I find every option?

Run lyria-cli --help. Use --timeout to set a request deadline and --overwrite when you intend to replace an existing output. Duration and tempo are prompt instructions, not exact guarantees.
